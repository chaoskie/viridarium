# D-002: AGPL-3.0-or-later

Status: ratified, 2026-06-07.

## Decision

The project is licensed AGPL-3.0-or-later.

## Why

For network-delivered self-hosted apps, the AGPL closes the SaaS loophole: whoever hosts a
modified version must publish its source. Precedents: Nextcloud, Mastodon.

## Trade-off accepted

Slower corporate adoption, which does not matter for this project's goals.
