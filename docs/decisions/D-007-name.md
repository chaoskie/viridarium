# D-007: The name Viridarium

Status: ratified, 2026-06-07.

## Decision

The project is named **Viridarium** (slug `viridarium`). It is a real, attested Latin
word: the green pleasure-garden of a Roman villa.

## Why

Three naming rounds:

1. English: "Plantkeep". Clean, but safe.
2. Dutch-English: "Plantsoen". Charming, but the wink only works for Dutch readers.
3. Latin: "Viridarium". A real word, semantically exact (a curated green collection),
   easy to pronounce, and unclaimed on GitHub, npm and PyPI.

## Consequences

- Repository `chaoskie/viridarium`, Python package `viridarium`, image
  `ghcr.io/chaoskie/viridarium`.
- The name set the visual direction, see [D-006, D-008, D-011](D-006-themes.md).
